A4 Duplex Matte Printing Guide: Print on heavyweight uncoated matte cardstock (250+ GSM) to avoid glare. Page 1 = Clean Card Fronts (photo + code only, zero text over the photo). Page 2 = Mirrored Attribution Backs (mirror horizontally in horizontal row pairs if printing duplex, or print two-sided flip on long edge — columns on Page 2 are swapped L↔R so backs align behind fronts!).
