# Known Limitations

This document records every incomplete integration, placeholder component, assumed model parameter, and unmeasured benchmark in **Lunar Aurora** at its current repository state. Nothing listed here is simulated or claimed as production-ready.

---

## 1. Sony Spatial Reality Display (ELF-SR1) Plugin Absent
- **Current behavior:** Sony's proprietary `SRDisplayUnityPlugin` is **not** installed in `src/kiosk_unity/Packages/manifest.json`, and `SRDISPLAY_SDK_PRESENT` is **not** defined in `src/kiosk_unity/ProjectSettings/ProjectSettings.asset`.
- **Impact:** `LunarAurora_Kiosk.exe` runs strictly in **`No-SRD simulation mode`** using `KioskSimulationCameraRig` on a standard display, with operator controls routed to **`Operator HUD (second display)`** (`KioskOperatorDisplayHUD`). Head-tracked lenticular 3D output is **not** functional yet.
- **Resolution:** Complete [docs/sony_srd_integration_todo.md](sony_srd_integration_todo.md) after downloading Sony's plugin and verifying Sony's class names on physical hardware.

## 2. Vision Classifier Untrained (`model.json` Missing)
- **Current behavior:** Training video captures for `data/cards/` have not been recorded from printed carving cards yet, so `src/frontend_webxr/assets/vision_model/model.json` is not present.
- **Impact:** Tapping **`[SCAN RELIC]`** in mobile WebXR displays **`"Vision model not installed"`** and does not infer any monument (all score-boosting, COCO-SSD keyword hacks, and step fallbacks were removed).
- **Resolution:** Print `docs/carving_cards/print_5_carving_cards.html`, film `<class>__session_XX.mp4` plus background clips (blank cardstock & card backs), extract frames via `tools/extract_frames.py`, and run `src/backend/train_classifier.py`.

## 3. Procedural 3D Placeholders (Not Archaeological Scans)
- **Current behavior:** All bundled `.glb` files in `src/frontend_webxr/assets/models/` and `src/kiosk_unity/SonyPlayer_3DAssets/` were procedurally generated from primitive geometry by `src/kiosk_unity/generate_glb_exhibits.py`. Only `Grand_Solstice_Sun_Temple.glb` is rendered in WebXR for `shore_temple_vimana` and labeled **`"Illustrative model"`**. Cards 02–05 display their Wikimedia Commons photograph and sourced facts panel. Similarly, the Unity Kiosk renders 3 procedural placeholders (`ShoreTemple`, `PanchaRathas`, `KrishnasButterball`) labeled `"Illustrative model"`.
- **Impact:** Displayed 3D geometry is conceptual/illustrative and not dimensionally accurate archaeology.
- **Resolution:** Drop team-authored `.glb` meshes into `src/frontend_webxr/assets/models/` per `src/frontend_webxr/assets/models/README_MODELS_TODO.md`.

## 4. Assumed / Illustrative Route Graph & Shade Weights
- **What is real:** Stop latitudes/longitudes and all 13 `PathEdge` walking distances (`distance_meters`) in `src/backend/init_db.py` are computed from OpenStreetMap (ODbL) footway/street geometry across Mahabalipuram.
- **What is assumed:** All per-edge `path_type` assignments, `base_shade_factor` weights (`0.10–0.94`), solar-elevation modulation functions in `routing_service.py`, Dijkstra penalty factor (`2.8`), and walking speed (`70.0 m/min`) are **assumed/illustrative** placeholders. They do **not** represent physically measured irradiance, pyranometer readings, UV exposure, or thermal comfort surveys.
- **Resolution:** Follow the **"How to calibrate"** guide in [README.md](../README.md) and [docs/ax.md](ax.md).

## 5. Unmeasured Benchmarks & Device KPIs
- **Groq Online AI (`GROQ_API_KEY` missing):** `src/backend/benchmark_kpis.py` skips Groq + Edge-TTS live latency as **`"NOT MEASURED - no API key"`** when `GROQ_API_KEY` is unset. Offline cached audio (`54` MP3s) and `OFFLINE_QA_BANK` fallback operate instead.
- **Field Device Profiling Pending:** `mobile_fps`, `qr_to_ar_launch_ms`, `vision_on_device_ms`, and `unity_frame_time_ms` remain **`"MEASURE ON DEVICE"`** until profiled on physical Android phones and ELF-SR1 hardware.
- **Self-Signed LAN HTTPS Warning:** `https://<LAN-IP>:8443` uses a self-signed certificate generated by `generate_ssl_certs.py`, requiring initial browser certificate acceptance for mobile camera access.
